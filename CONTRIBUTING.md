# Contributing to Pocket Arcade

Open an issue to discuss a bug or feature, or submit a pull request with a focused change. Describe what changed and how you verified it. For a gameplay or layout change, include the game, controls, and viewport you tested.

From the repository root, install dependencies and run the checks.

```sh
npm ci
npm test
npm run build
```

In Windows PowerShell, use `npm.cmd` if the npm PowerShell shim is blocked.

## Contributor agreement

Before opening a pull request, read the [Pocket Arcade Contributor License Agreement](CLA.md). Confirm your agreement in the pull request by checking the box in the template, or post this statement in the pull request:

> I agree to the Pocket Arcade Contributor License Agreement version 1.0 for my contributions in this pull request, and I confirm that I have authority to grant its rights.

The maintainer checks that each contributor whose work is included has agreed before merging. If an employer or another organization owns your work, have an authorized representative agree on its behalf before the contribution is merged. Identify the source and license of any third-party material in the pull request so the maintainer can review it separately.
